## 3. Issues found and fixed during development

| Issue | Fix |
|---|---|
| Horizontal "wings" and holes in outer garments over several layers | Distance functions made continuous and slope-normalised (layer stacking, drapes, region cuts, neckline), far field exact to 16 cm, small holes filled |
| Pockets of a blazer stretched to the wrists | Trim placement ignores sleeve panels |
| Hijab / hood open at the back of the head over a hair mass; brims over the eyes | Head coverings sized to the hair; forehead ease reduced |
| Tucked T-shirt made a ledge under trousers; T-shirt over overalls | Tucked tops shortened and fitted; overalls are a full-body layer that tucks tops in, with a real bib and straps |
| Long hair over the face, strands caught in the parting | Face kept clear; strands grow on a crease-free version of the hair volume |
| Belt plate rendered sideways | Rectangular sweep orientation fixed |
| Validator accepted Voxel documents and rejected unset colours | Voxel documents refused early; `null` accepted for "use the hair colour" / "same iris" |
| Saving froze the page for seconds (thumbnail render target recompiled every PBR shader) | Thumbnail drawn on the viewport canvas in a corner, inside the normal frame |
| GLB: vertex colours above 1, skinned meshes under a parent node | Colours clamped and stored as 16-bit, skinned meshes exported as root nodes; also 16-bit indices and no unused UVs (−11 % file size) |

## 4. Known limits

| Area | Limit |
|---|---|
| Cloth | Garments are fitted, not simulated (except scarves, shawls, keffiyeh). They follow the skeleton through skin weights; strong poses can show stretching or small intersections. |
| Layering | Extreme stacks (puffer over coat over hoodie over shirt) can still show small intersections. |
| Hair | Sculpted mass + strand geometry; no hair physics. Very curly and coily styles are approximated. |
| Weight | 250 k–740 k triangles, 9–25 MB per GLB: heavy for phones; see N3D_LIMONAT_INTEGRATION.md. |
| Animation | idle / walk / wave are procedural test clips. |
| Speed | Rebuilding after a body change takes seconds (the whole outfit is refitted). |
| VRM | Bone names are VRM humanoid; the `VRMC_vrm` extension itself is not written. |
| Thumbnails | Picker thumbnails are pre-rendered on a mannequin (`npm run thumbs`), not on the current character. |
| Real devices | Not yet tested on a physical phone. |
